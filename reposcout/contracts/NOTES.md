# Contract decisions for review

- File paths must already be canonical. Empty components, dot components, parent components, backslashes, NUL bytes and Windows drive prefixes are rejected. Files can contain spaces or Unicode. The filesystem-owning index must enforce symlink containment when reading. A root directory listing uses "." and does not construct a file Span.
- A Span with equal endpoints identifies one line. Line numbers and counters are strict integers. Scores and timings must be finite. The shared Pydantic base rejects extra fields. Models validate on construction and JSON deserialization.
- Symbol kinds are module, class, function and method. Async definitions use their synchronous kind. The module qualname is <module>. The default parent is null and is_test defaults to false. Symbol lookup, citation bounds and nesting require the actual index.
- SearchHit.source is an open string to accommodate fusion and future retrieval methods. Hits and candidates may be file-only. A citation can point to supporting evidence in a different file. A producer supplies the citation list explicitly.
- Ranked lists preserve insertion order and duplicates on ingestion so the evaluator can score saved predictions consistently. Producers apply the tie-break rules in AGENTS.md. Gold lists default to empty for interactive use. Repository IDs and commit strings are opaque here so the fixture can use local Git repositories.
- Counts and latency start at zero. A retrieval-only run may leave model null. Status is required. An error run needs a nonblank diagnostic. Format-repair events and their outcome belong in per-instance traces for aggregation by the evaluation runner.
- Zero call or round budgets permit retrieval-only execution. Requested output sizes and timeout must be positive. Workstream-specific ranking weights, retrieval limits and tool display caps can be defined in a typed config subclass that preserves the base defaults.
- The parser and index factory in contracts are signature-only stubs. B owns the runtime implementations and exports in reposcout.index. A imports the concrete parser from reposcout.index.parser as specified. RepoIndex.read returns the actual displayed span. When a read has no representable line (empty file or wholly out-of-range request), the implementation may raise ValueError, which dispatch converts to a tool error.
- ToolSpec carries the parameter schema as JSON data. The provider adapter wraps that schema in the OpenAI function envelope. ToolResult always includes an explicit citations list and truncation flag.
- Chat is synchronous and text-only. Tools are passed as a list (empty disables tools). The timeout is in seconds. Tool arguments remain raw JSON strings for dispatch to validate. Both the returned assistant message and the top-level result carry the same calls for transcript replay and direct access. Unsupported provider finish reasons are client errors.
- Registration accepts zero-argument factories, including localizer classes, preserves the decorated object and rejects empty or duplicate names. The consuming CLI or runner imports the built-in localizer modules before lookup.
